# Definitions

You always start with a definition when giving Clojure talks. So lets start with defining A **Feature Extreme framework**. A Feature Extreme framework is
a framework that pushes one of its core principles everywhere. For instance scheme, the language, where everything is a list. In clojure where 90% of what you are doing is using a function. And for other cases Flutter where everything is a widget.

# The Beauty

Frameworks that do this allow extractions. And what a freaking beauty extractions are. The lsp allows you to take part of the code and build another class or function there by cleaning out the code.
